# Multi-Agent Clinical Trial System

## Project Overview

Multi-Agent Clinical Trial is a collaborative academic project focused on exploring the use of multiple AI agents in clinical trial-related workflows.

The project follows a modular architecture with separate backend, frontend, data, and script components.

## Key Components

- **Backend:** Server-side application and processing components.
- **Frontend:** User-facing application interface.
- **Data:** Raw project data resources.
- **Scripts:** Supporting scripts for project workflows.
- **Multi-Agent Approach:** Designed around the coordination of multiple agents for task-oriented workflows.
